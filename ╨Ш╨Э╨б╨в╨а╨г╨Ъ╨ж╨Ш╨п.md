# Nizay — версия без базы данных (локальный режим)

Сервер, Cloudflare и база больше не нужны: аккаунты и ключи работают прямо в лаунчере.
Папка api/, setup.bat и make-admin.bat удалены.

## Настройка (один раз) — launcher\config.json
- "adminNames": логины администраторов (у вас NIZAYINA).
- "keySecret": придумайте длинный случайный секрет. Им подписываются ключи: меняйте ДО сборки и не меняйте потом,
  иначе ранее выданные ключи перестанут работать. Админский и обычный exe должны быть собраны с одним секретом.
- "apiUrl": оставьте пустым. Если когда-нибудь поднимете сервер — впишите адрес, лаунчер переключится на него.

## Сборка через GitHub
1. Загрузите папку в ПРИВАТНЫЙ репозиторий.
2. Actions -> Build Nizay -> Run workflow.
3. Артефакты: nizay-mod (jar), nizay-launcher (для друзей), nizay-launcher-admin (только для вас).

## Сборка локально
launcher\build-exe.bat -> launcher\dist\user\Nizay client.exe и launcher\dist\admin\Nizay client Admin.exe

## Как пользоваться
1. Запустите Admin-exe, зарегистрируйтесь с логином из adminNames — появится вкладка «Ключи».
2. Ключи -> тип -> Создать -> отправьте ключ другу.
3. Друг запускает обычный exe, регистрируется, Подписка -> вводит ключ.
4. Забыл пароль: Ключи -> «Сброс пароля» -> имя друга -> отправьте ему код (действует 30–60 минут).

## Ограничения локального режима
- Аккаунты хранятся на компьютере каждого человека; админ видит в списке только аккаунты со своего ПК.
- Один и тот же ключ можно активировать на разных компьютерах (общей базы «использован» нет). Пробный ключ — один раз на устройство.
- Кто умеет распаковывать exe, может достать keySecret и выпускать ключи. Для защиты от этого нужен сервер.
